Pudding Sword
============================================================

A Windows animated cursor theme generated from the supplied character art.

  * 15 cursors, 32x32, 21 steps of 100 ms (2.1 s loop)
  * every cursor type has its own pose and motion
  * install: double-click install.bat   (no administrator needed)
  * remove : double-click uninstall.bat
