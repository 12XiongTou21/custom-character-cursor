# 🖱️ 光标合集 / Custom Character Cursors

精选 Windows 自定义鼠标光标，按作品 IP 分类整理，开箱即用。

## ✨ 特性

- **50+ 套主题**：原神、鸣潮、绝区零、VTuber、葬送的芙莉莲、怪物猎人、赛博朋克等
- **按 IP 分文件夹**：`鸣潮/` `原神/` `绝区零/` `动漫/` `VTuber/` ...
- **右键即装**：每个角色文件夹里都带 `Install.inf`，右键 → 安装即可
- **动画光标**：全部为 `.ani` 动画指针，非静态

## 📂 目录结构

```
光标合集/
├── 鸣潮/     长离 · 守岸人 · 赞妮 · 卡梅莉亚 · 坎特蕾拉 · 卡尔罗塔 · 卡瑟尼娅
├── 原神/     芙宁娜2.0 · 阿蕾奇诺 · 玛薇卡 · 诺艾尔 · 流浪者
├── 绝区零/   艾莲·乔
├── VTuber/   Neuro-sama · 诗音·诺薇拉
├── 动漫/     芙莉莲 · 阿尼亚 · 祢豆子 · 千早爱音
├── 怪物猎人/ 艾露猫系列（弓/大剑/无武器）
└── 系统风格/ Win11 深浅色 · Cinnamon · 赛博朋克
```

## 🚀 使用

1. 进入对应角色文件夹
2. 右键 `Install.inf` → **安装**
3. `控制面板 → 鼠标 → 指针` 里选中方案
